# Проект команды на Обнинском хакатоне 2026

Команда не программирует: весь код пишет ИИ. Главное — чтобы проект всегда запускался и деплоился. Объясняй по-русски и простыми словами.

## Стек (не менять)

- Бэкенд: Python 3.13, FastAPI, SQLModel, SQLite. Зависимости через uv: `cd backend && uv add <пакет>` (не pip).
- Фронтенд: React 19 + TypeScript + Vite, Tailwind CSS v4, shadcn/ui (Radix), иконки lucide-react.
  - Роутинг: react-router v7, импорт из `react-router` (не `react-router-dom`).
  - Карты: react-leaflet. Графики: компонент `chart` из shadcn (recharts).
- ИИ: только через `ask_llm()` из `backend/app/llm.py`.
- Не добавляй библиотеку, если задачу решают уже установленные. Не переходи на другие фреймворки (Next.js, Django, Redux, MUI и т. п.).

## Структура

- `backend/app/main.py` — приложение, подключение роутеров
- `backend/app/models.py` — таблицы и схемы данных
- `backend/app/routers/` — эндпоинты, файл на раздел
- `backend/app/seed.py` — демо-данные для показа жюри
- `backend/app/llm.py` — нейросеть
- `backend/tests/` — тесты API
- `frontend/src/pages/` — страницы; `App.tsx` — маршруты; `components/Layout.tsx` — шапка и меню
- `frontend/src/components/ui/` — компоненты shadcn. Новые добавлять командой `cd frontend && npx shadcn@latest add <имя>`
- `frontend/src/lib/api.ts` — все запросы к API и их типы
- `frontend/src/config.ts` — название проекта, центр карты
- `deploy/`, `.github/` — сервер и автодеплой. Не трогать без прямой просьбы.

## Запуск

- Первый раз: `npm run setup`, затем `cp .env.example .env`
- Разработка: `npm run dev` → http://localhost:5173 (API на :8010, документация http://localhost:8010/api/docs)
- Проверка: `npm run check` (сборка фронтенда + тесты бэкенда). Если упало — чини, не коммить.

## Правила кода

- Все эндпоинты начинаются с `/api/`, иначе на сервере они не заработают. Новый роутер подключай в `main.py`.
- Новая сущность: модель в `models.py` → роутер в `routers/` → тест в `tests/` → типы и функции в `lib/api.ts` → страница.
- Поменял модели — увеличь `SCHEMA_VERSION` в `db.py`: база пересоздастся из `seed.py`. Демо-данные добавляй в `seed.py`.
- Фронтенд обращается к API только через `lib/api.ts` по относительным путям `/api/...`. Никаких `http://localhost:8010` в коде.
- Интерфейс на русском, аккуратный, удобный на телефоне. Используй компоненты shadcn и классы Tailwind, свой CSS — только если без него никак.
- Ошибки показывай через `toast.error(...)` из `sonner`.
- Ключи и пароли только в `.env` (пример — `.env.example`). Никогда не вставляй их в код и не коммить.
- Персональные данные (ФИО, телефоны, диагнозы) — только выдуманные.

## Git

- Перед началом работы: `git pull --rebase`.
- После каждого работающего шага: `npm run check`, коммит, `git push`. Пуш в `main` сам выкатывает сайт за 1–2 минуты.
- Сообщение коммита — одна короткая строка по-русски, без описания. Не добавляй `Co-Authored-By` и упоминаний ИИ.
- Конфликт при pull — разреши, сохранив изменения обеих сторон, и снова запусти `npm run check`.
- Деплой упал — смотри `gh run list` и `gh run view --log-failed`.
